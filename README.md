# QVAC Offline Translator

A simple offline English-to-French translator powered by Tether's QVAC SDK.

The application loads a translation model and performs translation locally through QVAC.

## Features

- English-to-French translation
- On-device AI inference
- Uses Tether's QVAC SDK
- Simple command-line interface
- No external translation API required

## Requirements

- Node.js 22+
- npm
- Internet connection for the initial model download

## Installation

Clone the repository:

```bash
git clone https://github.com/chimayzz/qvac-offline-translator.git
